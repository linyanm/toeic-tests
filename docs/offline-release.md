# 电脑离线版：下载、解压、双击使用

下载附件 **toeic-offline.zip**（不是 Source code），完整解压后双击文件夹中的 **开始练习.html**，用电脑上的 Edge 或 Chrome 打开。

- 不需要购买服务、VPN、Node.js、Python、本地服务器或登录；下载完成后的练习不需要联网。
- 包含四套 800 题、216 段题目/题组音频、4 套连续录音、原书图片与中文解析、听力/阅读错题、1041 条带词性的词汇。
- 保留备份与恢复功能。在线版记录不会自动迁移，请先导出 JSON，再在离线版导入。
- 请固定文件夹位置。换电脑、换浏览器、移动文件夹、升级或清理数据前先备份。
- GitHub 下载在部分国内网络下可能不畅；取得完整包后，离线练习不再依赖 GitHub 或其他网站。
- 包内不包含任何个人学习记录、账号凭据或原 PDF；第三方材料的授权边界见仓库 README。

附件 `toeic-offline.zip.sha256` 可用于校验下载完整性。

## 验证范围

- 16 项自动测试通过：练习引擎、离线数据零网络加载、完整脚本执行、选项隐藏/揭晓、本地音频路径、记录保存/重新加载、备份恢复、词性与在线加载回归。
- 四套 800 题、216 段独立音频、1041 条词汇及引用图片资源校验通过；ZIP 文件逐项校验内容和路径。
- 当前执行环境没有连接可用浏览器，因此**未完成真实浏览器的双击渲染与音频播放验收**。脚本执行测试使用 DOM 适配器，不等同于浏览器或音频解码测试；遇到问题请提供浏览器版本和截图。
