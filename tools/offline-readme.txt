托业全真练习 · TOEIC 电脑离线版

【开始使用】
1. 将整个 ZIP 压缩包解压到一个固定文件夹，不能在压缩包预览中直接打开。
2. 双击“开始练习.html”，用电脑上的 Edge 或 Chrome 打开。
3. 不需要安装 Node.js、Python、启动服务器、登录账号或连接网络。
4. 请保留 HTML、两个 JS 文件、styles.css、images 和 media 的相对位置。
   不要只复制 HTML，也不要删除图片或录音文件夹。

【保留功能】
四套 800 题、整套模拟和听力/阅读专项、逐题/题组录音、完整听力录音、
原书图片、长阅读、中文解析、听力/阅读错题归类、1041 条词汇及词性。
Part 1 / 2 作答时只显示选项字母，提交后显示英文选项与解析。

【录音】
需要点击播放器或“重听本题”播放，浏览器不会无条件自动播放声音。
录音失败时先确认已经完整解压，media 文件夹仍与 HTML 位于同一目录。

【学习记录——请务必阅读】
记录存于当前浏览器，不写回压缩包或题库文件，也不会发送到服务器。
本地文件的浏览器存储行为存在差异。请使用正常窗口，不使用隐私/无痕模式。
建议始终使用同一个浏览器和固定文件夹，一次只开一个作答窗口。
移动/重命名文件夹、换浏览器、换电脑、更新离线包或清理浏览器数据前，
请在首页点击“备份学习记录”，保存下载的 JSON 文件。
在新的离线包首页点击“恢复学习记录”，选择该备份，再确认导入。
在线版的记录不会自动出现在离线版；也需要先备份，再导入。
如果浏览器禁止存储，当前页面仍可练习，但关闭前必须备份。

【分享与更新】
无需把自己的备份 JSON 发给别人；发布压缩包中不包含任何用户学习记录。
使用说明与新版下载：https://github.com/GrittingLeo/toeic-four-tests
GitHub 在部分网络下可能访问不畅；可以先下载完整包再通过合适的文件传输渠道交付。
下载离线包之后，正常练习不再依赖 GitHub 或任何在线服务。
